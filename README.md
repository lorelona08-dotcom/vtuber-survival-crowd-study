1만 발 유지 창의 2,400개 물리 틱과 3만 발 이동 창의 1,440개 틱에서 실제 활성 적탄 하한을 지켰습니다. 3만 발 이동 중 보스가 직접 발사한 탄은 순간 19~113발이었고, 나머지에는 다른 원작 적탄과 실험이 보충한 직선탄이 포함됩니다. 같은 창에서 군중 그림의 최장 간격은 1만 발 89.4ms, 3만 발 86.5ms였습니다. 평균 FPS가 높아도 순간적으로 군중 그림이 멈칫할 수 있습니다.

3만 발 시험의 첫 12초를 맞춰 추가 적탄의 벽 충돌 효과만 비교했습니다. 원작 불꽃 처리에서 평균 14.2 FPS, P95 95.8ms였고, 같은 불꽃을 모아 그리면 64.7 FPS, P95 20.9ms였습니다. 두 경로 모두 벽 충돌당 원작 불꽃 3개를 생성합니다. [벽 불꽃을 원작 처리로 재현](https://lorelona08-dotcom.github.io/vtuber-survival-crowd-study/?v=mixed-r7&preset=mixed&mode=optimized&count=100000&seed=7&wallfx=native)

- **원작 방어를 적용한 혼합 광역기 1회.** 재생성 후 세 번 모두 실제로 99,957~99,970마리가 죽었습니다. 잠복·벽·방어·높은 HP를 가진 적이 30~43마리 남았습니다. 공격 순간 최장 프레임은 29.2~41.7ms였습니다.
- **초기 혼합 무리 전원 처치.** 처음 100,000마리 중 실제 사망 100,000, 자연 이탈 0, 생존 0이었습니다. 원작 광역기 45회, 게임 시간 24.68초, 발생 XP 160,778입니다. 이후 소환된 52마리는 별도로 집계했습니다.
- **단일 구성 일격과 일반 웨이브.** 단일 구성에서는 2회 모두 광역기 한 번으로 10만 마리가 전멸하고 10만 XP가 발생했습니다. 공격 순간 최장 프레임은 12.6~16.8ms였습니다. 일반 플레이에서는 원래 혼합 웨이브와 5분 보스를 확인했습니다. 개선판의 전투 구간은 평균 239.8 FPS, P95 4.3ms였습니다.

스크린샷은 측정 창이 끝난 직후의 실제 화면입니다. 화면 하단은 계속 갱신되는 최근 5초의 값이고 표는 명시된 시험 구간의 값입니다.

## 검증과 재현

프레임은 실제 전투 중 브라우저 rAF에서 기록하고, 군중 그림은 워커가 계산한 새 결과가 게임에 반영될 때마다 따로 측정합니다. 조작, 실제 생존·피격·XP, 게임 시간의 진행률은 같은 기록에 포함됩니다. 데스크톱과 모바일은 브라우저와 기기별로 성능이 달라집니다.

```console
python qa/mixed.py --seconds 40
python qa/mixed.py --floor 30000 --case cycles --cycles 3 --seconds 3
python qa/mixed.py --case finish
python qa/play.py --case normal --headed --seconds 30
```
